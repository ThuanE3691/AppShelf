# Template credits

The three AppShelf templates (`restaurant`, `agency`, `services`) are original
work made for this personal demo project.

## Images

Every image in `*/assets/` is an original SVG illustration drawn for AppShelf
by hand-written SVG code (flat shapes, no traced or embedded photos, no
third-party artwork). They are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) together with the
rest of the template content.

No stock photos, icon packs or Unsplash images are used.

## Fonts

No font files are shipped or loaded. The themes use the visitor's system font
stacks (for example `system-ui`, Segoe UI, Roboto, Georgia, Palatino), so there
are no font licences to track and no external font requests.

## Copy

All business names, people, addresses, phone numbers (555 range), email
addresses (`.example` domain), prices, reviews and clients are fictional.
Any resemblance to a real business is unintended.

## Code

Theme code and block markup: GPL-2.0-or-later, like WordPress.
